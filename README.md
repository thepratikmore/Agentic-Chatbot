### End to End Project Agentic AI Chatbots

# 🤖 Agentic Chatbot
An AI-powered chatbot built using LangGraph, LangChain, Streamlit, and Groq LLM that demonstrates agentic workflows with an interactive user interface.

## Project Overview
Agentic Chatbot is a modular AI application built to explore Agentic AI concepts using LangGraph. The project demonstrates how Large Language Models can be orchestrated through graph-based workflows to solve user queries efficiently. It features a clean Streamlit interface and supports multiple AI use cases.


## ✨ Features
- 🤖 AI-powered chatbot
- 🔄 LangGraph workflow management
- 🧠 Groq LLM integration
- 💬 Interactive Streamlit UI
- 📂 Modular project architecture
- ⚡ Fast inference
- 🔧 Easy configuration using environment variables

## 🛠 Tech Stack

## ⚙️ Installation
git clone https://github.com/thepratikmore/Agentic-Chatbot.git

cd Agentic-Chatbot

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt



## 🔐Environment Variables
GROQ_API_KEY=your_api_key



## ▶️ Run the project
streamlit run app.py
